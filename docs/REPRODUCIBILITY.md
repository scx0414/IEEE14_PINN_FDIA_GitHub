# 复现说明

## 保留的科学定义

1. 当前状态估计，输入包含当前量测；不是仅用历史预测当前状态。
2. 输出全部14个Vm和13个非参考相角，不硬编码PV电压。
3. 原模型家族各用合适结构和训练配方；没有强制统一参数。
4. 训练损失为batch物理量组归一化的监督与AC损失加权和。
5. 威布尔拟合对象是一时刻的系统最大节点残差，不是所有节点误差混合，不是KL。
6. 阈值拟合只读取正常数据，评估期间冻结；理论虚警与实际误报分别报告。
7. 连续攻击保留真实输入历史，攻击后报警仍按当前正常标签计误报。

## 重构的边界

- 已有检查点的参数命名/结构保持兼容，发布验证记录位于`docs/VALIDATION.json`。
- 便携训练入口使用eager优化，没有搬入依赖大量历史脚本的CUDA Graph训练程序；它不承诺优化轨迹逐位一致。
- 新训练默认16840训练时刻；原冻结旧权重最初使用14508训练时刻及截至18135的模型选择数据。运行路线A时不改变这些旧权重。
- 原来的历史试验（KL、Transformer、图注意力、首轮MLP等）保留在研究工作目录，没有混入当前发布包。
- 本包当前只提供连续攻击主线；先前DDET独立窗口实验的结果不与连续15步结果混为一谈。
- 后续不同噪声、季度、电网的泛化能力需要独立评估；三个初始化种子不代表独立数据集置信区间。

## 可选MATLAB BDD

安装MATPOWER并配置路径后：

```bash
python -m ieee14_fdia export-matlab --attacks runs/tang15 --network examples/ieee14_network.json --output runs/matlab_inputs
```

在MATLAB中将本仓库`matlab`目录加入路径，再执行：

```matlab
check_bdd('runs/matlab_inputs', 'runs/bdd_results');
```

检查器对每个时刻从同一盲平坦初值运行AC-WLS，不从真实/伪造状态初始化；未知量为14Vm和13theta，无额外PV电压/零注入硬约束。默认sigma0.001pu，J=r'R^(-1)r，95%卡方自由度1阈值3.841458820694126。保存通过、失败与不收敛状态，不筛除攻击。MATPOWER需提供`dSbus_dV`。

BDD残差检查的置信水平95%与神经网络威布尔目标虚警5%是两套不同检验。Python生成器未运行MATLAB时，不会自动给出或声称BDD通过。
